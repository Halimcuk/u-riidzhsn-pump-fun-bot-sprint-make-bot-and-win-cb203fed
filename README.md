This entry, the create-slot surge scalper, is a paper-trading bot for the "Pump.fun Bot Sprint: Make Bot And Win" bounty on make.fun: it watches every new pump.fun coin from its creation event and buys only when the coin's real SOL reserve first crosses above 20 SOL in the very slot it was created, spending a fixed 0.05 SOL per coin and never entering the same coin twice, then sells the whole position at +10% take profit, −10% stop loss, or after a maximum hold of 100 slots, whichever comes first.

```sh
node main.ts
```
